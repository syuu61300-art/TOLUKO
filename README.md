# トルコアイス🍦 絶対取ったるゲーム

トルコアイスを取らせない店主から、アイスを奪い取るブラウザゲームです。単一の `index.html` だけで動きます(ビルド不要・外部ライブラリなし)。

## 遊び方
- 手を動かして、**つかむボタン**(PCはスペース/Enterキー、スマホは画面上のボタン)を押す
- つかんだ瞬間に手がアイスに届いていれば勝ち。外すとライフが減る
- スタート前に3秒のカウントダウン

## モード
簡単 → 普通 → 難しい → 激ムズの順に解放されます。クリアすると次のモードが開き、結果画面の「次へ」ボタンで進めます(クリア状況はlocalStorageに保存)。

| モード | 特徴 |
|---|---|
| 簡単 | 遅く、逃げ方もゆるい。ライフ5 |
| 普通 | 標準。ライフ4 |
| 難しい | 速く、ワープあり。ライフ3 |
| 激ムズ | 超高速で鋭く逃げ、判定も小さい。ライフ3、制限時間20秒 |

## 設定
最初のモード選択画面の「⚙️ つかむボタンの設定」から、ボタンの位置(ドラッグまたはプリセット)と透明度を変更できます。ドラッグしたあと「保存」を押すと反映されます(キャンセルで破棄)。ボタンの大きさは110px固定です。設定はブラウザの localStorage に保存されます。

## 起動
`index.html` をブラウザで開くだけです。

### GitHub Pages で公開
1. このフォルダの中身をリポジトリのルートに置いて push
2. Settings → Pages → Branch を `main` / `(root)` に設定
3. 表示された URL で遊べます
